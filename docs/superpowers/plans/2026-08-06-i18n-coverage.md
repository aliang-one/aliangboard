# i18n 覆盖修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 消除 AliangBoard 前端全部用户可见的硬编码中文字符串，使其经 vue-i18n 的 `t()`/`i18n.global.t()` 走国际化；`en.json` 保持完整翻译，zh/en 键对齐。

**Architecture:** 全部新串归入 `src/locales/{zh,en}.json` 的命名空间，键名 `namespace.camelCaseLeaf`。组件（`.vue`）用 `useI18n()` 的 `t()`；非组件 `.js` 模块用既有 `import { i18n } from '@/i18n'` → `i18n.global.t()`。客观验收靠自研零依赖检查器 `scripts/i18n-check.mjs`（残存中文扫描 + 键对齐），辅以 `npm run build`（编译所有 `.vue`）与 `npm run typecheck`。

**Tech Stack:** Vue 3 + vue-i18n@11（`legacy:false`），纯 JS（零新增依赖政策——检查器用 Node 内置模块）。

## Global Constraints

- **零新增依赖**（仓库政策）：检查器/合并工具用 Node 内置 `fs`/`path`/`node:test`，不引第三方。
- **键命名**：`namespace.camelCaseLeaf`；通用词复用现有 `common.*`（save/cancel/delete/search/sync/loading/success/error/confirm/close/edit/create/apply/yes/no/none…），不重复造；视图专属串归入该视图命名空间（已有则扩展，如 `workloadDetail.*`/`podDetail.*`/`store.*`/`admin.*`）；无合适归属时新建以视图名命名的命名空间（如 `nsWorkloadDetail`、`nsServiceDetail`、`admin.apiKeys`、`ingressPerf`）。
- **`.vue` 取用**：`import { useI18n } from 'vue-i18n'; const { t } = useI18n()`；模板用 `t(...)`（非 `$t`）。
- **`.js` 取用**：`import { i18n } from '@/i18n'` → `i18n.global.t('ns.key', params)`。
- **插值**：值内 `{var}` → `t('key', { var })`；值内允许 HTML（现有模式）。
- **双语必填**：每个新键同时写入 `zh.json`（中文）与 `en.json`（英文）。
- **翻译范围**：纳入——模板可见文本、UI 属性（`title`/`placeholder`/`aria-label`/`alt`/`label`/`content`）、`ElMessage`/`ElNotification`/`ElMessageBox`/`notify`/`alert`/`confirm`、用户可见 `throw new Error(...)`。排除——纯 `console.*`、代码注释、`src/mock/**` 种子数据、`**/__tests__/**`、专有名词/品牌词（`zh.json` 中已刻意保留英文者，如 "Nodes"/"Resource Utilization"，保持不动）。
- **每任务结束**：跑该任务范围对应的检查器 + `npm run build` + `npm run typecheck`，绿了再提交。

## Conversion Procedure（所有转换任务的统一「怎么做」，含真实示例）

对每个文件，按下述模式把硬编码中文替换为 `t()`/`i18n.global.t()`，并把新键同时加进 `zh.json` 与 `en.json`。**改属性/动态绑定时务必加 `:` 前缀变成表达式。**

**模式 A — `.vue` 模板文本节点**
```vue
<!-- before -->
<span>刷新</span>
<!-- after -->
<span>{{ t('common.sync') }}</span>
```

**模式 B — `.vue` 静态属性（必须改动态绑定 `:`）**
```vue
<!-- before -->
<button title="刷新">
<!-- after -->
<button :title="t('common.sync')">
```

**模式 C — `.vue` 脚本侧 `ElMessage` + 插值**
```js
// before
ElMessage.success(`已重启 ${name}`)
// after（在 useI18n() 的 t 作用域内）
ElMessage.success(t('podDetail.restartSuccess', { name }))
// zh.json: "podDetail": { "restartSuccess": "已重启 {name}" }
// en.json: "podDetail": { "restartSuccess": "Restarted {name}" }
```

**模式 D — `.js` 模块（store/composable/api/router），用 `i18n.global.t`**
```js
// before (src/stores/cluster.js)
notify('error', `${label}创建失败：${e.message || '请检查 YAML 与权限'}`)
// after
import { i18n } from '@/i18n'
notify('error', i18n.global.t('store.createFailed', { label, msg: e.message || i18n.global.t('store.checkYamlPerm') }))
// zh: "store": { "createFailed": "{label}创建失败：{msg}", "checkYamlPerm": "请检查 YAML 与权限" }
// en: "store": { "createFailed": "Failed to create {label}: {msg}", "checkYamlPerm": "Check the YAML and permissions" }
```

**模式 E — `router/index.js` 的 `meta.title`（响应式陷阱）**
路由 `meta` 在模块加载时求值，直接存翻译串不会随语言切换更新。**存 i18n 键，在渲染处翻译**：
```js
// before
meta: { title: '选择集群' }
// after
meta: { titleKey: 'selectCluster.title' }   // 存键，不存翻译
```
渲染处（如面包屑/页头）改为 `t($route.meta.titleKey)`。转换前先 `grep -rn "meta.title"` 找全所有读取点，逐处改；若某处只用于 `document.title`，用 `watchEffect` 在 locale 变化时重设。

**去重规则**：每写一个新键前，先在 `zh.json` 里搜同义已有键（尤其 `common.*`）；相同语义复用，避免 `deleteSuccess` 这类在多视图重复。

- [ ] **Step 4: 实现 `scripts/i18n-check.mjs`**

```js
// 自研零依赖检查器：扫残存用户可见中文 + zh/en 键对齐
import fs from 'node:fs'
import path from 'node:path'
import { pathToFileURL } from 'node:url'

const CJK = /[一-鿿]/
const SKIP = ['node_modules', 'locales', 'mock']          // 路径片段
const isSkip = (p) => SKIP.some(s => p.includes(s)) || /(__tests__|\.test\.)/.test(p)
const loadJson = (f) => JSON.parse(fs.readFileSync(new URL(f, import.meta.url), 'utf8'))

// 纯扫描：不过滤路径（路径过滤由 walk 负责），便于测试直接对夹具调用
export function scanSource(file) {
  if (!fs.existsSync(file)) return []
  const hits = []
  const lines = fs.readFileSync(file, 'utf8').split('\n')
  let inBlock = false
  lines.forEach((raw, i) => {
    if (!CJK.test(raw)) return
    const t = raw.trim()
    if (inBlock) { if (t.includes('*/')) inBlock = false; return }
    if (/^(\/\/|\/\*|\*|<!--|-->)/.test(t)) { if (t.startsWith('/*') && !t.includes('*/')) inBlock = true; return }
    if (/console\.(log|warn|error|info|debug)\s*\(/.test(raw)) return
    hits.push({ file, line: i + 1, text: t })
  })
  return hits
}

function walk(d, out = []) {
  for (const e of fs.readdirSync(d, { withFileTypes: true })) {
    const p = path.join(d, e.name)
    if (isSkip(p)) continue
    if (e.isDirectory()) walk(p, out)
    else if (/\.(vue|js|mjs)$/.test(e.name)) out.push(p)
  }
  return out
}

function flat(o, p = '') {
  const r = []
  for (const k in o) { const kk = p ? `${p}.${k}` : k; if (o[k] && typeof o[k] === 'object' && !Array.isArray(o[k])) r.push(...flat(o[k], kk)); else r.push(kk) }
  return r
}

export function parity() {
  const zh = loadJson('../src/locales/zh.json'), en = loadJson('../src/locales/en.json')
  const fz = new Set(flat(zh)), fe = new Set(flat(en))
  return { onlyZh: [...fz].filter(k => !fe.has(k)), onlyEn: [...fe].filter(k => !fz.has(k)) }
}

if (import.meta.url === pathToFileURL(process.argv[1]).href) {
  const roots = process.argv.slice(2).length ? process.argv.slice(2) : ['src']
  let files = []
  for (const r of roots) files.push(...(fs.statSync(r).isDirectory() ? walk(r) : [r]))
  let total = 0
  for (const f of files) { const h = scanSource(f); if (h.length) { total += h.length; console.log(`\n${f}  (${h.length})`); h.forEach(x => console.log(`  ${x.line}: ${x.text}`)) } }
  const { onlyZh, onlyEn } = parity()
  console.log(`\n残存中文行：${total}`)
  if (onlyZh.length || onlyEn.length) console.log(`键不对齐：onlyZh=${onlyZh.length} onlyEn=${onlyEn.length}`, { onlyZh, onlyEn })
  else console.log('键对齐：✓')
  process.exit(total > 0 || onlyZh.length || onlyEn.length ? 1 : 0)
}
```

## 风险与缓解（执行时牢记）

| 风险 | 缓解 |
|---|---|
