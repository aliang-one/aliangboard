# 工作台项目生命周期 — 手测/运维清单

特性:项目删除(级联)/重命名/项目 recap 人工编辑(2026-08-31,分支 feat/workbench-project-lifecycle)。

> **网关须重启一次**:本特性含服务端改动(数据层删除事务、DELETE/PATCH 路由、摘要器加固)。旧网关进程不重启则新端点 404、新注入头不生效。

## 通用前置

- 网关已重启(`server/` 进程重启,确认启动日志无 `<db>.lock` 拒启)。
- 平台账号登录(项目 **owner 或 admin**);⑥ 另需注册至少一台 SSH 服务器。① 无需 SSH——项目 repo 目录在网关侧,不在任何 pod 内。

## ① 删项目:级联全清

1. 工作台 → 项目 tab → 新建一个一次性项目(如 `tmp-lifecycle-test`)。
2. 在该项目下发起至少 1 个 AI 对话(产生消息)。项目 repo 目录在**网关侧** `WORKBENCH_DIR`(默认 `data/workbench/projects/<projectId>`),不是对话目标 pod 内的路径。
3. 项目列表中点该项目的删除按钮。
4. 确认弹窗要求**输入项目名**确认;输入 `tmp-lifecycle-test` 并确认。
5. **预期**:
   - 项目列表中该行消失;
   - 关联对话全部删除:直接访问旧对话 ID(如旧 URL)→ 404;
   - 网关侧 repo 目录已删除:到网关容器/主机上确认 `data/workbench/projects/<projectId>` 不存在(无需进任何 pod,terminal 不适用)。

## ② 删除确认名不符被拒

1. 对任一项目点删除。
2. 弹窗中输入**与项目名不符**的任意文本(或留空),点确认。
3. **预期**:前端拒绝提交/后端 **400**,项目仍在列表中,无任何数据变化。

## ③ 项目重命名

1. 项目列表中对目标项目点重命名(行内编辑)。
2. 改为新名(如 `-v2` 后缀)回车提交。
3. **预期**:
   - 列表行即时显示新名;刷新页面仍为新名(非重命名竞态回退);
   - 重名冲突时提示错误且**原保留旧名**;
   - 项目下对话、recap、绑定关系不受影响。

## ④ recap 编辑/清空 → 新对话注入变化

1. 打开工作台对话界面,展开**透明面板**(提示词透明面板,展示实际注入内容)。
2. 找到项目 recap 卡(项目记忆),点编辑。
3. 改写 recap 内容(如加一句 `MANUAL-TEST-MARKER`),保存;再测一次清空。
4. **预期**:
   - 编辑后新发一个对话,透明面板中注入的项目记忆包含 `MANUAL-TEST-MARKER`;
   - 清空后新对话注入中项目记忆块消失(或为空),agent 行为不再受旧 recap 影响;
   - 旧对话不受影响(注入按新对话取值)。

## ⑤ 摘要器 caveat 出现在新对话提示词

1. 任一项目下,让 agent 跑几轮工具(产生可摘要内容),等待 recap 生成/或手动编辑 recap 后。
2. 新建对话,展开透明面板查看注入的系统提示片段。
3. **预期**:项目记忆注入头带**确切的 caveat 字面** `(历史经验供参考;工具与能力以本轮实际提供的为准)`,而非无条件断言能力(该字面与对话级 recap 注入头一致)。

## ⑥ 旧毒项目(全局分析)清 recap 后恢复 SSH 工具调用

> 背景:摘要器曾把「无 SSH 能力」类瞬时结论写入记忆,导致后续对话 agent 拒绝调用 SSH 工具。

1. 打开历史上出现过该症状的项目(全局分析类项目)。
2. 项目记忆卡 → **清空** recap。
3. 在该项目下新发对话,要求 agent 在 SSH 服务器上执行命令(如 `ls`)。
4. **预期**:agent 正常调用 SSH 工具并返回结果,不再以「无法 SSH」为由拒绝。

## 运维备注

- 删除为**硬删除**(DB 级联单事务:conversations / messages / history / last_reconcile / 项目行),无软删回收;确认名机制是唯一防误删闸门(前后端都按 trim 后逐字比对)。
- DELETE/PATCH 端点 **owner 或 admin** 可调,已在 `ROUTE_AUTH` 登记;非 owner 且非 admin 调用 → 403。
- repo 目录在**网关侧 `WORKBENCH_DIR`**(默认 `data/workbench/…`,不在 pod 内),删除前做了逃逸校验(resolve 后必须落在 `WORKBENCH_DIR` 内)。清除失败**不阻塞 DB 删除**:HTTP 仍 200 但响应带 `warning`,网关日志落 `[workbench] 项目 repo 目录删除失败: <原因>`,需人工跟进孤儿目录。
